Questions

Before you install

Do I need to be a programmer?

No. You talk to siteseo in plain English inside Claude Code, and it explains every problem it finds. It works best with your website's files on your computer, so it can check changes before you publish and make fixes for you.

Will it change my website without asking?

No. It shows you each change first and writes nothing until you say so.

Does it guarantee I'll show up in AI answers?

No tool can promise that, and siteseo doesn't. It removes what stops assistants from reading your site, and then measures how often they name you, so you can see whether things are moving.

How do I get updates?

In Claude Code, run /plugin, open the Installed tab, choose siteseo and select Update now. What changed in each version is on the releases page.
